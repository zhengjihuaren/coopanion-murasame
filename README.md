# 丛雨 · Coopanion 桌宠形象包

一个二头身的和风少女：浅绿色双马尾各系一条粉红蝴蝶结，白色花纹和服配黑色腰带，脚上木屐；
侧身朝右站着，能站、能坐、能走能跑，被拎起来也不怕。

## 安装

1. 下载 Releases 里的 `murasame-v1.0.0.zip`（不用解压）。
2. 打开 Coopanion → 「装扮」→「形象」→「导入」，选中这个 zip。
3. 导入完成后，在形象列表里选「丛雨」。

也可以导入解压出来的 `murasame` 文件夹。
